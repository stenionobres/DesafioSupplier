# Desafio Supplier

Aplicação criada com o objetivo de implementar uma Api básica de registro de Usuários, Clientes e suas Transações.

## Instruções

O que precisa ser instalado na máquina para executar, estender e depurar o projeto:

    Visual Studio Community 2022 ou superior;
    .NET 8 ou superior;
    RabbitMQ;

**Passo a passo para execução**

    * Entrar na pasta /src/DesafioSupplier.Api;
    * Ajustar as configs de geração do token e os dados de servidor do RabbitMQ no arquivo appsettings.Development.json;
    * Caso prefira pode adicionar as configs usando o secrets do .NET;
    * Executar o projeto DesafioSupplier.Api no Visual Studio. O Swagger vai ser inicializado;
	* Fazer signin com o email: email@example.com, senha: 102030;
	* Caso prefira use o endpoint signup para criar seu usuário e senha;
